# Project Support Assistant — ideal target

*Fictional planning artifact for Harbour Learning Network; not a candidate CV.*

## Profile

Project support professional seeking a Project Support Assistant role, with a focus on keeping schedules and task records current, coordinating meetings, surfacing dependencies, and following through on actions. Communicates project changes clearly, adapts to shifting priorities, and works collaboratively to resolve routine delivery issues in a remote Canadian team.

## Relevant experience themes

- Maintains project schedules and task trackers, clarifying owners, due dates, status, and dependencies so participants can see what needs attention.
- Coordinates project meetings by arranging times, sharing agendas and materials, recording decisions and actions, and following up with owners.
- Monitors open actions and dependencies, checks in with participants, and raises emerging delays or blockers to the project lead.
- Shares concise updates when timelines, tasks, or dependencies change, making the effect on participants and next steps clear.
- Supports budget tracking by keeping planned and actual costs organized, documenting updates, and flagging variances for review.
- Helps teams work through routine coordination problems, reprioritizes follow-up as needs change, and keeps project records usable by others.

## Project support capabilities

Schedule maintenance; task and action tracking; meeting coordination; dependency follow-up; status updates; change communication; budget tracking; project record keeping; adaptable organization; collaborative problem solving.

## Preferred qualification

Project management certification.

## Ways of working

Organized and responsive across concurrent tasks. Confirms ownership and next steps, communicates changes promptly, and adjusts follow-up when project needs shift. Comfortable coordinating remotely with participants across Canada.
