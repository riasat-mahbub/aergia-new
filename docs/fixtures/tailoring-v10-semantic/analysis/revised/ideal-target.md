# Junior Data Analyst

## Profile

Junior data analyst who turns inconsistent tabular data into reliable, understandable evidence for community research. Uses Python and SQL to clean, validate, and investigate records, then communicates findings, uncertainty, and limitations in clear reports for nontechnical project partners.

## Core capabilities

**Data preparation and quality:** Inspect unfamiliar datasets, standardize formats, handle missing or duplicate values with documented rules, validate fields and relationships, and preserve traceability from source records to analysis-ready data. Investigate anomalies and conflicting records, distinguish data errors from meaningful variation, and flag unresolved issues instead of silently changing the evidence.

**Analysis and reporting:** Use Python and SQL to query, join, summarize, and check tabular data. Select methods that fit the question and data quality, verify results with practical checks, and explain what the analysis supports and what it cannot establish. Produce concise tables, visual summaries, and reports that make methods, definitions, caveats, and key findings easy to understand.

**Communication and collaboration:** Clarify project questions and data definitions with research colleagues and community partners. Share progress and assumptions, translate technical details into plain language, listen to partner context, and adapt reporting to the decisions people need to make. Work carefully with sensitive or incomplete information and raise quality concerns early.

## Relevant work approach

For each analysis, establish the source, structure, and intended meaning of the data before transforming it. Apply repeatable cleaning and validation steps, check row counts and key fields before and after changes, and keep a record of assumptions and unresolved exceptions. Use exploratory summaries to investigate inconsistencies, then confirm that reported results can be reproduced from the prepared data.

Present results with enough context to support responsible interpretation: define measures, describe important data limitations, separate observed patterns from conclusions, and identify where more information is needed. Use Tableau or Power BI when an interactive dashboard or visual report helps partners explore results; choose a simpler format when it communicates the answer more clearly.

## Tools

Python for data cleaning, validation, and analysis; SQL for querying and joining relational tables; Tableau or Power BI for dashboards and visual reporting. Apply versioned, documented workflows that make transformations and outputs straightforward to review and reproduce.

## Work setting

Collaborative, remote work with research teams and project partners across Canada, with clear written updates and reliable handoffs.
