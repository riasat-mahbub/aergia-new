# Junior Data Analyst

## Profile

Junior data analyst prepared to clean and validate tabular data, investigate inconsistent records, and turn analysis into clear reports for nontechnical project partners. Uses Python and SQL to organize and examine data, with a careful approach to documenting assumptions, limitations, and findings; ready to apply Tableau or Power BI for accessible visual reporting.

## Relevant Experience

### Data preparation and quality

Clean tabular data with Python and SQL, check field types and expected ranges, identify missing or duplicate values, and reconcile inconsistent records against source information and agreed rules. Keep transformations reproducible and record validation decisions so project partners can understand how the analysis was prepared.

### Analysis and reporting

Explore datasets to answer practical research questions, summarize patterns with appropriate tables and visualizations, and explain what the data supports. Prepare concise reports that distinguish findings from assumptions, describe limitations, and give nontechnical readers enough context to use the results responsibly.

## Projects

### Data quality and reporting project

Use Python and SQL to prepare a tabular dataset, investigate anomalies, and produce a documented analysis. Present key findings and data limitations in a concise report or dashboard, choosing Tableau or Power BI when an interactive view would help partners explore the results.

## Skills

Python for data cleaning, validation, exploration, and repeatable analysis; SQL for selecting, joining, aggregating, and checking tabular data; data quality review; descriptive analysis; clear tables and charts; report writing; Tableau or Power BI; documentation of methods, assumptions, and limitations.

## Ways of Working

Work carefully with source data, ask clarifying questions when definitions or records are unclear, and communicate progress and limitations in plain language. Collaborate with research and project partners to confirm that analysis addresses their questions, explain findings without overstating certainty, and keep notes that make the work understandable and reproducible.
