# Junior Software Developer

## Profile
Junior software developer focused on building and maintaining Python API integrations. Brings careful problem solving to automated testing, edge-case investigation, and clear interface documentation, and works well with teammates through code review and shared CI workflows. Familiar with Docker and ready to grow production deployment experience while contributing reliable, maintainable changes.

## Relevant Experience Themes

### Python API Integrations
Develop and maintain Python integrations that exchange data across services. Clarify interface behavior, handle expected and unexpected responses, and investigate edge cases so failures are understandable and changes remain compatible with existing consumers.

### Automated Testing and CI
Add focused automated tests for normal flows, invalid inputs, and boundary conditions. Contribute to CI workflows that run checks consistently, use failures to find regressions, and make small, reviewable changes that are straightforward to maintain.

### Documentation and Team Delivery
Document API interfaces, assumptions, and setup steps in concise language for other developers. Collaborate through code review, respond constructively to feedback, communicate investigation findings, and keep implementation choices aligned with the needs of the wider team.

## Relevant Project Focus

### Service Integration Work
Build a small Python service or client that consumes an API, validates responses, and handles timeouts and error cases. Include tests for successful and unsuccessful responses, a clear description of the interface, and a repeatable local development setup using Docker where appropriate.

## Technical Skills
Python; HTTP APIs and JSON; automated testing; CI workflows; Git and code review; interface documentation; Docker fundamentals; debugging and edge-case analysis; production deployment fundamentals.

## Ways of Working
Approaches unfamiliar systems with curiosity and care, breaks problems into reviewable steps, and explains findings clearly. Values dependable tests, useful documentation, and collaborative feedback, while building deeper experience with production operations and deployment.
