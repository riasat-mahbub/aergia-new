## `README.md` plan

Goal: the entry point a new contributor (or future agent) needs to
understand the project in 5 minutes, find the dev setup, and
discover the deeper docs.

### Structure (target ~250 lines)

```markdown
# Aergia CV Builder

A single-user CV builder. FastAPI + React, HTML-first rendering.
The Python HTML renderer produces both the live preview and the PDF;
the React tree is the editor surface, never the renderer.

## What it does

(1 paragraph: user signs in, edits CV in a schematic editor, picks a
template, exports PDF. Three system templates ship: modern/classic/minimal.)

## Quick start (dev)

(2-3 commands: clone, ./dev.sh, open localhost:5173. Link to ./dev.sh
for the flags.)

## Architecture (1 paragraph + 5-line diagram)

(Pull the diagram from AGENTS.md "Architecture & Data Flow" verbatim.
Add a 1-paragraph explanation of AST → Resolver → Renderer.)

## Templates

(How templates work: manifest JSON → resolver → renderer. Link to
TEMPLATE_GUIDE.md or fold the manifest reference here if the doc is
deleted. Highlight the closed vocabulary: zones, placement,
layout_defaults, policy_overrides, global_styles.)

## Project structure

(api/, web/, scripts/, tracker/, docs/. List each with one line.)

## Dev commands

(Table: dev.sh flags, codegen regen, smoke gate, tests, lint.)
```
