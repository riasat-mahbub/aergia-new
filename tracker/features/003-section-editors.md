## Description

Seven section types, each with an editor component and a renderer component:
- **Profile**: name, title, email, phone, location, summary, photo
- **Experience**: company, position, dates, description, tech stack (repeatable)
- **Education**: school, degree, dates, GPA, description (repeatable)
- **Skills**: categories with skill items and proficiency levels
- **Projects**: name, description, dates, tech stack, links (repeatable)
- **Languages**: language name with proficiency bar
- **Certifications**: name, issuer, date, description (repeatable)

All editors support repeatable entries with accordion UI and drag-to-reorder.
