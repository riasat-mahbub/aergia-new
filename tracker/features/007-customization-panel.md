## Description

CustomizePanel provides controls for:
- Colors: accent, sidebar background, header, divider, text, heading
- Fonts: body font, heading font (previewed via Google Fonts)
- Spacing: section gap slider
- All changes reflected live in the preview via CSS custom properties
- Per-instance style overrides (font, color, weight) added in Phase 10.5
