## Description

Integrate with an LLM (OpenAI, local model, etc.) to:
- Suggest better bullet points for experience/education entries
- Rewrite summary for impact
- Generate skill proficiency descriptions
- Button per entry: "Suggest improvement"

The renderer backend architecture already supports this via the plugegable
backend pattern.
