## Description

Right-pane preview in the builder shows a live rendering of the CV:
- Updates in real-time as sections are edited
- Template switching between Modern, Classic, Minimal, and user templates
- Uses `UserTemplateRenderer` (iframe with `srcdoc`) for all templates
- Print styles match PDF output
- Default customizations applied from template
