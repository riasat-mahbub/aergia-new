# Field-style row UI polish and profile center default

## Background

FieldStyleRow previously laid out Bold/Italic labels in a row where the Italic label sat beside the Bold checkbox (labels not adjacent to their own controls), and the color control took a full row for a swatch + hex. Redesigned: each toggle is a checkbox wrapped by its own label, size and color are compact inline units, and the row wraps responsively on mobile/tablet/desktop. Profile sections now default to text-align center (type-level default, overridable per-section) via _default_subsection in the builders.
